# 开发路线

目标始终是 Windows + macOS 的可开源长按语音入口工具。

## 当前基础版本

已具备共享引擎、两端系统适配源代码、设置／多配置界面、探测与恢复子进程、核心及界面测试。

## 下一阶段

- Windows 实体鼠标 + 真实语音软件闭环验证；识别 Codex、浏览器、微信、飞书实际控件树。
- Mac 实机验证权限、鼠标配对、修饰键和输入法，以及已实现的 Electron AXManualAccessibility 启用路径。
- 活动会话焦点保护的真实应用验证，以及已接入的 Windows 系统通知和 Mac 休眠／切出通知在真实转换过程中的释放验证。
- 鼠标队列压力和恢复进程失败后重建已有模型／界面测试；继续验证真实输入法下的循环异常和恢复进程失联。
- 快捷键录入、运行应用选择器、规则编辑器与延迟检查工具已实现；继续进行实体键盘及 Mac 原生事件验证，完善中英文界面。
- 原生平台集成测试覆盖 Hook 注入标记、按键部分失败、崩溃恢复及实体键竞争。
- 可选的显式替代手势，用于系统接口不能确认的输入框；不能自动降低默认识别标准。

## 发布准备

- Windows 自包含便携包与签名策略；macOS `.app` 签名、公证及权限迁移验证。
- 真实版本兼容性清单、隐私说明、问题模板、第三方许可与可复现构建。
- GitHub CI 的 Windows/Mac 构建及测试需实际执行后才能标记通过。

尚未发布到 GitHub，也未创建远程仓库。
