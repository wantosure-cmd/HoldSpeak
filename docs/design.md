# 左键说 · HoldSpeak

推荐中文名「左键说」，直接表达鼠标左键和说话。副标题「按住左键，让想法成文」。暂保留英文工程名 HoldSpeak、程序名及配置目录，避免打断已有配置和启动脚本。候选名「按住说」更强调动作、「左键语音」更偏工具；名称未进行商标或产品重名检索。

## 界面

依据 Ant Design 的设计令牌、信息层级与布局语言，在现有 Avalonia 桌面界面实现。没有嵌入 React 或引入 WebView。官方参考：https://ant.design/docs/react/customize-theme/

采用浅色背景 #F5F7FA、白色容器、主蓝 #1677FF，正文 #101828、辅助文字 #667085、边框 #EAECF0。控件圆角 6、容器圆角 10，间距基于 4px；字号 12/13/14/20/24。固定品牌与状态区，下方侧栏和独立滚动内容，避免整个窗口滚动导致状态不可见。

导航：常规设置、语音软件、应用规则、高级配置、诊断与帮助。状态由实际引擎驱动，显示「快捷键保持中」而不虚构已确认录音；中断原因在提示区域保留，避免鼠标松开或下一次悬停覆盖原因。

## Logo

branding/leftspeak.svg 是原创可缩放矢量：蓝色圆角底、白色鼠标轮廓、实心左键、右侧声波。应用窗体、主界面和托盘使用同一几何。许可证沿用项目 MIT。不要用麦克风图标代替鼠标左键，避免误以为这是独立转录软件。

## 目标中断

0.1.14 起按用户最新要求，默认完全去掉输入框判断：全局长按，到时发送快捷键，松开结束；不执行悬停或活动目标探测，切应用／窗口不中断。界面显示全局模式，并移除宽松开关。文字是否能写入以及写入的位置，由语音输入法与键盘焦点决定。以下仅描述高级 JSON 关闭 `triggerAnywhere` 后的旧检测路径。

持续说话期间检查当前焦点编辑器，不再每 500ms 对最初鼠标位置进行命中测试。0.1.13 起按用户要求默认宽松模式：无法确认的区域允许触发，超时允许继续；明确只读、密码、按钮等不可输入控件仍拒绝。宽松模式仍约束前台应用和窗口；两次均明确识别为编辑器且身份改变时结束。未知目标无法提供精确的输入框身份保证。关闭常规页的宽松模式开关恢复严格检测与超时结束。

Antigravity 实际只读探测发现根 Document 暴露只读 ValuePattern，没有 TextPattern 和编辑子控件；因此按未知网页容器处理。该结论不代表真实录音与回填已通过，需要用户在目标输入框复测。
